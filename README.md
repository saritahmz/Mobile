# BeautyCompare PWA

Requisitos implementados cumulativamente:

1. Thumb-Friendly Zone: barra de navegação inferior, botão principal de pesquisa amplo e elementos de toque confortáveis.
2. Skeleton Loading: cards cinzas pulsantes aparecem durante a busca assíncrona, substituindo o spinner tradicional.

A função `fakeFirebaseSearch()` simula a espera do Firebase com `setTimeout`. Para usar Firebase real, substitua essa função pela consulta ao Firestore ou Realtime Database.

Teste sugerido: Marca `Maybelline` e Categoria `Base`.
